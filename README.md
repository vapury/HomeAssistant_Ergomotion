# Ergomotion Smart Beds for Home Assistant

Custom integration for Ergomotion Bluetooth Smart Beds & Tempur Zero-G Curve.

## Features
- Head / Foot Motor control (`cover`)
- Preset buttons (Zero-G, Flat, TV, Anti-Snore) (`button`)
- Massage intensity & timer (`number`, `select`)
- Bed underlight control (`light`)
- Real-time connection & battery status (`sensor`, `binary_sensor`)

## Installation via HACS
1. Open HACS in Home Assistant.
2. Go to **Integrations** > **Custom repositories**.
3. Add `https://github.com/vapury/HomeAssistant_Ergomotion` as **Integration**.
4. Download and restart Home Assistant.
